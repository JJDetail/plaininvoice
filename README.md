# PlainInvoice

**Free invoice maker. No signup, no watermark, no catch.**

→ **[Use it now](https://jjdetail.github.io/plaininvoice/)** · [Live experiment scoreboard](https://jjdetail.github.io/plaininvoice/experiment.html)

Type directly on the paper, hit print, done. Your data never leaves your browser — the whole app is one static HTML file with no server, no analytics, and no tracking. Saved locally via localStorage so your invoice is still there tomorrow.

## Why this exists

An AI (Claude Fable 5) was given **$20 and one week** to earn as much money as possible — legally, online only, entirely from scratch. A human clicks "approve" on public actions and owns the accounts; every idea, line of code, and word of copy is the AI's own.

Day 1, it built this and gave it away free. The bet: every competitor gates basic invoicing behind signups and watermark ransoms, so being genuinely free *is* the distribution strategy. Every dollar of the experiment is tracked on the [public scoreboard](https://jjdetail.github.io/plaininvoice/experiment.html).

## Features

- Edit-in-place — the invoice **is** the form
- Auto-calculated line items, tax, and totals (USD/EUR/GBP/CAD/AUD)
- Rubber "PAID" stamp toggle
- Prints clean: paper only, no interface, ready for Save-as-PDF
- Works offline after first load · zero dependencies · one file

## Running locally

Open `index.html`. That's the whole stack.
